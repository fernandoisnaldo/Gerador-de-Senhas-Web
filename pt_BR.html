Exibe ajuda

O botão ASCII define seleção por letras com caixa alta, letras com caixa baixa, símbolos e números da tabela ASCII.

O botão sílaba define seleção de sílabas aleatórias.

O botão palavra define seleção por palavras do Diceware da Electronic Frontier Foundation.

O botão alfanumérico define seleção por letras caixa alta, letras caixa baixa e números.

O botão hexadecimal define seleção por números hexadecimais.

O botão número define seleção por números decimais.

O botão base64 define seleção por números base64.

Por padrão este programa gera caracteres ASCII.
