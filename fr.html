Afficher l'aide

Le bouton ASCII définit la sélection à partir de lettres majuscules, lettres minuscules, symboles et chiffres de la table ASCII.

Le bouton syllable définit la sélection de syllabes aléatoires.

Le bouton mot définit la sélection à partir de mots de la liste Diceware de l'Electronic Frontier Foundation.

Le bouton alphanumérique définit la sélection à partir de lettres majuscules, lettres minuscules et chiffres.

Le bouton hexadécimal définit la sélection à partir de nombres hexadécimaux.

Le bouton nombre définit la sélection à partir de chiffres décimaux.

Le bouton base64 définit la sélection à partir de caractères base64.

Par défaut, ce programme génère des caractères ASCII.
