The ASCII button defines selection by uppercase letters, lowercase letters, symbols, and numbers from the ASCII table.

The syllables button defines selection of random syllables.

The alphanumeric button defines selection by uppercase letters, lowercase letters, and numbers.

The hexadecimal button defines selection by hexadecimal numbers.

The numbers button defines selection by decimal numbers.

The base64 button defines selection by base64 numbers.

By default, this program generates ASCII characters.
