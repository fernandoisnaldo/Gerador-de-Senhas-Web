The ASCII button sets selection using uppercase letters, lowercase letters, symbols, and numbers from the ASCII table.

The syllable button sets selection to random syllables.

The word button sets selection using words from the Electronic Frontier Foundation's Diceware list.

The alphanumeric button sets selection using uppercase letters, lowercase letters, and numbers.

The hexadecimal button sets selection using hexadecimal numbers.

The number button sets selection using decimal numbers.

The base64 button sets selection using base64 characters.

By default, this program generates ASCII characters.
